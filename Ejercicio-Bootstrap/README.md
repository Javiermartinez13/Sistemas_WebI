# Ejercicio Bootstrap

## Descripción

Página web introductoria sobre baloncesto realizada para practicar Bootstrap
5.3.3 y el diseño responsive.

## Archivos

- `index.html`: página principal del ejercicio.

## Funcionamiento

- Navbar responsive con menú colapsable.
- Cards para explicar tres posiciones del equipo.
- Botones, alerta, lista y formulario de contacto.
- Carrusel con tres imágenes.
- Sistema de columnas con `container`, `row`, `col-12`, `col-md-6` y `col-lg-4`.
- Distribución responsive con `col-lg-7`, `col-lg-5`, `col-lg-8` y `col-lg-4`.

## Cómo probarlo

Abre `index.html` directamente con un navegador. Es necesaria una conexión a
Internet para cargar Bootstrap y las imágenes externas mediante CDN.

## Tecnologías

- HTML5.
- Bootstrap 5.3.3.
- CDN.
