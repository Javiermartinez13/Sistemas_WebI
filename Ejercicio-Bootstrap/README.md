# Página de baloncesto con Bootstrap

Página web introductoria sobre baloncesto realizada para practicar Bootstrap 5.3.3.

## Contenido

- `index.html`: página principal.
- Bootstrap 5.3.3 cargado mediante CDN.
- Navbar responsive con menú colapsable.
- Cards para explicar tres posiciones del equipo.
- Botones, alerta contextual, lista y formulario de contacto.
- Carrusel con tres imágenes.

## Uso del Grid

La sección de posiciones utiliza `container`, `row` y columnas `col-12 col-md-6 col-lg-4`.
Por eso se muestran tres tarjetas en pantallas grandes, dos en pantallas medianas y una en móviles.
También se utiliza `col-lg-7` y `col-lg-5` en la cabecera, y `col-lg-8` y `col-lg-4` en la sección del carrusel.

## Cómo abrirlo

Abre `index.html` directamente con un navegador. Es necesaria una conexión a Internet para cargar Bootstrap y las imágenes externas mediante CDN.
