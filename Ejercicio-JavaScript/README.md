# Ejercicio JavaScript

## Descripción

Generador de contraseñas formado por palabras aleatorias de un diccionario.
La página permite personalizar el resultado con varias opciones.

## Archivos

- `ejercicio1.html`: estructura de la página y formulario.
- `style.css`: estilos visuales del generador.
- `script.js`: generación de contraseñas, validaciones y eventos.

## Funcionamiento

- Permite indicar el número de palabras.
- Puede poner en mayúscula la primera letra.
- Puede evitar palabras repetidas.
- Muestra mensajes cuando el número introducido no es válido o supera los
  límites establecidos.
- Une las palabras seleccionadas con guiones.

## Cómo probarlo

Abre `ejercicio1.html` directamente con un navegador. Introduce el número de
palabras, selecciona las opciones que quieras y pulsa **Generar contraseña**.

## Tecnologías

- HTML5.
- CSS3.
- JavaScript.
