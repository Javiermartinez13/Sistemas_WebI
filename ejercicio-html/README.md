# Ejercicio HTML

## Descripción

Página web sencilla sobre el ciclismo realizada para practicar la estructura
básica y semántica de HTML.

## Archivos

- `mi-bici.html`: página principal sobre la bicicleta.
- `bicicleta.svg`: imagen local utilizada en la página.
- `favicon.png`: icono de la página.

## Funcionamiento

- Cabecera, navegación, contenido principal, contenido complementario y pie de
  página.
- Encabezados, párrafos, enlaces, listas, imagen, tabla y enlaces internos.
- Texto destacado mediante las etiquetas `strong` y `em`.

## Cómo probarlo

Abre `mi-bici.html` directamente con un navegador. La imagen de la bicicleta se
carga desde el archivo local `bicicleta.svg`.

## Tecnologías

- HTML5.
- SVG.
