# Página sobre ciclismo

Página web sencilla sobre el ciclismo realizada para practicar la estructura básica de HTML.

## Contenido

- `mi-bici.html`: página principal sobre la bicicleta.
- Estructura semántica con cabecera, navegación, contenido principal, contenido complementario y pie de página.
- Encabezados, párrafos, enlaces, listas, imagen, tabla y enlaces internos.
- Texto destacado mediante las etiquetas `strong` y `em`.

## Cómo abrirla

Abre `mi-bici.html` directamente con un navegador. La imagen de la bicicleta se carga desde el archivo local `bicicleta.svg`.
